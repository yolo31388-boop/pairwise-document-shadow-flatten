# pairwise-document-shadow-flatten

## 领域

游戏、图形与多媒体

## 主题

文档阴影压平

## 说明

对台灯等点光源在文档照片上投下的硬边阴影做乘性压平，同时保住纸张米黄本色、
细笔画与跨页亮度一致性。管线针对六类典型失败逐一修复：

| 旧失败做法 | 修复 | 实现入口 |
| --- | --- | --- |
| 整图亮度除法，米黄被拉白、文字对比丢失 | 文字先 inpaint 剔除，再用**边缘保持双边滤波**低通分离照明场，乘性增益锚定纸张自身基准（受光纸 95 分位，低于纯白），保色保对比 | `shadow_lowpass_separate` / `flatten` |
| 模糊核写死 51px，高分辨率上仍是硬线 | 核长（双边直径、形态学核、羽化 sigma）全部按图像最大边相对 1600px 参考宽缩放，且恒为奇数 | `kernel_by_resolution` |
| 文字被当阴影，自适应阈值压平细笔画 | 笔画掩码膨胀后 inpaint，照明估计看不到文字；二值化只做全局 Otsu + 连通域滤噪，不做局部自适应与腐蚀，2px 细笔画保持连通 | `text_region_protect` / `binarize` |
| 透视下整图单一增益，远端仍偏暗 | 网格分区中位数提供低频鲁棒锚，与逐像素照明融合成分区增益场，逐区补偿照明衰减 | `gain_per_region` |
| 逐张估计，翻页亮度一跳（5%） | 跨页鲁棒中位数作为共享基准，逐页目标偏差与相邻步长都钳在 5% 内，并给 EWMA 流式基准；显式基准下跳过单页锚定以保跨页线性 | `batch_baseline` |
| 硬边界除法后出现亮暗双边 | 双边滤波保留阴影边界几何（不用大高斯糊边），增益场再做分辨率尺度羽化，过冲受控 | `edge_feather` + `_illumination_lowpass` |

### 关键设计

- **边缘保持低通是消除双边的核心**：普通高斯把窄半影糊成宽坡，而增益是照明的
  倒数，估计偏差在边界被放大成亮暗双边。双边滤波的颜色 sigma 跨过平缓光照起伏、
  却小于硬边界对比度，因此纸张内部平滑、阴影边界几何保留。
- **亮区软膝 + 头空**：受光区增益经 smoothstep 软膝压向 1，输出再统一硬压到
  250/255 以下，米黄永不被拉到纯白，且不引入新硬线。

### 入口

`imaging/document_shadow_flatten.py` 实现全部 15 个公共函数。对整数入参会落到
确定性合成文档上，因此每个入口都可独立演示、不依赖外部文件。

### 运行

```bash
python -m pytest -q          # 契约测试 + 六修复点行为测试（31 项）
python scripts/demo_pipeline.py   # 生成 artifacts/demo 可视化与审计 JSON
```

`metrics` 量化压平质量：纸张亮度变异系数、阴影消除率、文字对比保留率、纸色漂移、
边界梯度比与双边过冲（`bilateral_overshoot`，合格 < 0.05）。
